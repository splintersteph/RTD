# PlanProd — démo

Version de démonstration de PlanProd (planification de production, PDP, Gantt, fiabilité machines, gammes ABC…).

- Données **fictives / anonymisées** : noms de clients, numéros de commande, prix et quantités sont modifiés.
- Les dates sont recalées automatiquement sur la date du jour.
- Aucune modification n'est enregistrée : tout se passe dans le navigateur.

Ouvrir `index.html` via un serveur web (GitHub Pages : `/demo/`).
